3. IMPORTANT SECURITY MODEL
---------------------------
Never expose a permanent public URL to premium book files.

Recommended flow:
1. Member requests to read/download a book.
2. Backend authenticates member.
3. Backend checks entitlement/access.
4. Backend generates a short-lived signed URL OR streams/proxies the file.
5. Access event is logged.

Note:
A signed URL improves access control but is NOT full DRM. A determined user
may still copy content once access is legitimately granted.

5. ACCESS CHECK LOGIC
---------------------
function canAccess(user, book, action):
    if action == PREVIEW:
        return preview exists

    if book is FREE_FULL:
        return true

    entitlement = findValidEntitlement(user, book)

    if action == READ:
        return entitlement allows READ

    if action == DOWNLOAD:
        return entitlement allows DOWNLOAD

    return false

6. BORROW EXPIRATION
--------------------
Borrowing creates:
- entitlement/access record
- borrowed_at
- expires_at
- status

A scheduled job periodically marks expired borrowing records, or expiration
can be checked dynamically during every access request.
